# 3D Print Live — Brand Kit

Logo files and brand rules for 3D Print Live, a 3D printing business (prototypes, miniatures, decor, cosplay, architectural models, print-on-demand). Printing is "live": on demand and fast. Tagline (website only, never inside the logo): *"Building your idea one layer at a time."*

Use this file as context in Claude Code or Claude Desktop when building the website, packaging, social posts, etc.

## The logo
A half-printed isometric cube. The bottom layers are solid, with blue layer lines, and a dashed outline above shows the part still to come. A nozzle deposits the current layer, drawn as the apricot line. The name sits under the mark: "3D PRINT" in ink and "LIVE" in blue. Beneath the name is a rule that is half solid apricot and half dashed grey.

Only the **stacked** lockup (name under the mark) is used. Don't make a horizontal version.

## Colors
| Role | Hex | Use |
|---|---|---|
| Azure | `#0A7CFF` | Primary brand color: layer lines, avatar background, buttons |
| Azure (text) | `#0062D1` | "LIVE" and blue text on light backgrounds (passes contrast) |
| Azure (on dark) | `#5AA9FF` | Blue accents on dark backgrounds |
| Apricot | `#FF8A3D` | Secondary: the "live" extrusion line, rules, highlights; "LIVE" on dark |
| Ink | `#111418` | Text and dark backgrounds |
| Light ground | `#F4F5F7` | Light page background |
| Grey (dashed) | `#A3A9B3` | Dashed "unprinted" lines on light backgrounds |

Blue stands for what's already built and apricot for what's being printed right now. Keep that meaning when using the colors elsewhere.

## Typography
- **Nunito** (Google Fonts, free). Wordmark: uppercase, Bold 700, letter-spacing 0.1em; "LIVE" in Black 900.
- For website headings use Nunito 800–900; for body text use Nunito 400–600.

## Rules
- Keep clear space around the logo at least as wide as the letter "L" is tall.
- Minimum width: stacked logo 120px; mark 24px.
- Don't recolor, stretch or rotate the logo, add shadows, or put the tagline inside it.
- On photos, use the dark version on a dark overlay.
